# Privacy Policy for On the Fly

Last updated: June 23, 2026

On the Fly is a local-first Chrome extension that lets users visually customize webpages in their browser. Users can select, move, resize, hide, restyle, and save visual changes to websites.

## Data processed by the extension

On the Fly may process the following information locally in the browser:

* Website content needed to identify and edit page elements
* User editing activity, such as selections, clicks, drags, keyboard shortcuts, and saved visual changes
* Extension settings and page-specific customization data

This information is used only to provide the extension’s visual editing features.

## Local storage

On the Fly stores customization data locally on the user’s device using browser storage. This allows saved edits to persist across page refreshes and browser restarts.

## No backend or cloud collection

The public Chrome Web Store version of On the Fly does not use a backend server. It does not transmit website content, saved edits, browsing activity, analytics, or personal information to the developer or to a third-party service.

## No public AI service

The public Chrome Web Store version of On the Fly does not include AI processing and does not send page content or user instructions to an AI provider.

## Data sharing

On the Fly does not sell, share, or transfer user data to advertisers, data brokers, analytics providers, or other third parties.

## Remote code

On the Fly does not load or execute remote code. The extension code is packaged with the extension.

## User control

Users can clear saved page customizations from the extension. Users can also remove all extension data by uninstalling the extension or clearing the extension’s browser storage.

## Limited Use disclosure

On the Fly’s use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data handled by the extension is used only to provide or improve the extension’s single purpose: local visual editing of webpages.
